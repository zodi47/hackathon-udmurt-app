# Ӟеч-а бур-а удмурт кыл?

Приложение для изучения удмуртского языка для детей 5-10 лет. Приложение дает ребятам возможность погрузиться в родной язык в игровой форме приложения с дружелюбным интерфейсом в удмуртском стиле.

## Для кого

Дети 5-10 лет - и те, кто уже говорит на удмуртском, и те, кто только начинает. Приложение пригодится учителям для домашних заданий и дистанционных уроков, а родителям - чтобы заниматься вместе с ребенком.

## Зачем

Закрепить слова с уроков и сделать изучение языка игрой - крупные кнопки, яркий отклик и награда в конце. Заодно ребята знакомятся с культурой - цвета флага и удмуртский узор на каждом экране. Печатных пособий по языку хватает, а электронных нет - мы это исправляем.

## Что уже есть

Обучение - 10 тем и 78 слов из материалов кейса. Ребенок выбирает тему и листает карточки со словом и переводом.

Игра «Выбери перевод» - нужно выбрать правильный перевод удмуртского слова из четырех вариантов. Сначала верный ответ загорается зеленым с галочкой, потом неверный краснеет и покачивается, а в конце темы падают ромбики из орнамента.

Приложение работает без интернета и подстроено под телефон: крупные кнопки, цвета флага Удмуртии и узор на каждом экране. Профиль и настройки пока в разработке.

## Как запустить

Приложению нужен локальный сервер

Через Live Server в VS Code - открыть папку проекта целиком, затем `index.html` и нажать **Go Live** внизу справа.

Через Python - в папке проекта выполнить команду и открыть http://localhost:8000

```bash
python3 -m http.server 8000
```

Чтобы посмотреть как на телефоне - F12 и режим устройства (Ctrl+Shift+M, на Mac Cmd+Shift+M).

## Структура

```
index.html              главная
html/                   обучение, игры, профиль, настройки
css/style.css           все стили и анимации
js/loader.js            загрузка словаря
js/utils.js             общие функции
js/education.js         обучение
js/games.js             выбор игры и темы
js/games/translate.js   игра «Выбери перевод»
data/words.json         словарь
font/                   шрифт Noto Sans с удмуртскими буквами
```

## Технологии

HTML, CSS и JavaScript без фреймворков. Словарь лежит в JSON, поэтому новые темы добавляются без правки кода. Шрифт с удмуртскими буквами лежит внутри приложения, а анимации плавные даже на слабых телефонах.

## Планы

К очному этапу доделаем все по ТЗ:

- еще 5 игр - найди лишнее, сортировка, найди пару, собери слово и правда/ложь
- картинки, транскрипция и озвучка к каждому слову
- регистрация и сохранение прогресса
- профиль - факты об удмуртском языке и статистика
- настройки - звук, уведомления и геолокация
- слово дня и отчет для родителей и учителей

- сборка для Android 8+ и проверка на настоящих телефонах
