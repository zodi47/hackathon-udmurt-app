# Ӟеч-а бур-а удмурт кыл?

Тау! - приложение для изучения удмуртского языка для детей 5-10 лет. Приложение дает ребятам возможность погрузиться в родной язык в игровой форме приложения с дружелюбным интерфейсом в удмуртском стиле

## Что уже есть

Обучение - 10 тем и 78 слов из материалов кейса. Ребенок выбирает тему и листает карточки со словом и переводом.

Игра «Выбери перевод» - нужно выбрать правильный перевод удмуртского слова из четырех вариантов. Верный ответ загорается зеленым с галочкой, неверный краснеет и покачивается, а в конце темы падают ромбики из орнамента.

Приложение работает без интернета и подстроено под телефон: крупные кнопки, цвета флага Удмуртии и узор на каждом экране. Профиль и настройки пока в разработке.

## Как запустить

Приложению нужен локальный сервер - если открыть `index.html` двойным кликом, браузер не загрузит словарь.

Через Live Server в VS Code или VSCodium - открыть папку проекта целиком, затем `index.html` и нажать **Go Live** внизу справа.

Через Python - в папке проекта выполнить команду и открыть http://localhost:8000

```bash
python3 -m http.server 8000
```

Чтобы посмотреть как на телефоне - F12 и режим устройства (Ctrl+Shift+M, на Mac Cmd+Shift+M).

## Структура

```
index.html              главная
html/                   обучение, игры, профиль, настройки
css/style.css           все стили и анимации
js/loader.js            загрузка словаря
js/utils.js             общие функции
js/education.js         обучение
js/games.js             выбор игры и темы
js/games/translate.js   игра «Выбери перевод»
data/words.json         словарь
font/                   шрифт Noto Sans с удмуртскими буквами
```

## Технологии

HTML, CSS и JavaScript без фреймворков. Словарь лежит в JSON, поэтому новые темы добавляются без правки кода.
